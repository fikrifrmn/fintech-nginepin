# BlueFlame Stay - Hotel Website

## Overview
BlueFlame Stay is a modern, Gen Z-inspired hotel website featuring a futuristic neon-blue theme with electric purple accents. Designed for young travelers (18-30) who value stylish, digital-first experiences.

## Brand Identity
- **Name**: BlueFlame Stay
- **Tagline**: "Stay Cool, Stay Blue"
- **Target Audience**: Gen Z travelers, digital nomads, content creators
- **Color Palette**: 
  - Primary: #0F52BA (Flames Blue)
  - Secondary: #3F00FF (Electric Purple)
  - Accent: #89CFF0 (Sky Blue)

## Features
- Responsive navigation with smooth scrolling
- Full-screen hero with hotel imagery
- Room showcase (Standard, Deluxe, Suite)
- Facilities section with icons
- Auto-rotating testimonials carousel
- Newsletter signup in footer
- Hover glow effects throughout
- Complete booking flow (Login → Register → Booking → Payment)

## Pages
1. **index.html** - Landing page with all sections
2. **login.html** - User authentication
3. **register.html** - New user registration
4. **booking.html** - Room selection and booking form
5. **payment.html** - Checkout and payment processing
6. **admin.html** - Admin dashboard with analytics and booking management

## Tech Stack
- React 18
- TailwindCSS with custom theme
- Lucide Icons
- Google Fonts (Poppins)
- LocalStorage for user session

## Sections
1. Navbar - Logo and navigation
2. Hero - Full-screen with CTA
3. About - Gen Z concept description
4. Rooms - Interactive room cards
5. Facilities - Animated facility icons
6. Testimonials - Auto-carousel
7. Footer - Contact and social links

## Tone
Playful, energetic, Gen Z-friendly with casual microcopy like "Crash here, chill hard" and "Your vibes, our space."
