-----------------------NGINEP.IN-----------------------
Aplikasi web ini dikembangkan menggunakan Node.js, sehingga sebelum menjalankan aplikasi, wajib memastikan Node.js telah terpasang pada perangkat yang digunakan.

HOW TO RUN :

1. INSTALL NODE JS
2. INSTALL EXTENSI LIVE SERVER DI VS CODE
3. START SERVER -> NPM START
4. START FRONTEND PAKAI LIVE SERVER
5. SIMULASI PEMBAYARAN -> Sistem pembayaran pada aplikasi ini menggunakan Midtrans Sandbox, yaitu lingkungan simulasi yang digunakan khusus untuk keperluan pengujian, bukan transaksi nyata.

Agar proses pembayaran dapat dianggap berhasil, pengguna harus melakukan simulasi pembayaran secara manual melalui halaman Midtrans Sandbox.
Pada metode pembayaran QRIS, pengguna perlu menyalin alamat (URL) gambar QRIS yang ditampilkan oleh sistem, kemudian menempelkan (paste) alamat tersebut ke halaman simulasi pembayaran di Midtrans Sandbox untuk menyelesaikan proses pembayaran.
